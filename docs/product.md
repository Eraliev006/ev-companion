# E.V (Иви)

Иви живёт на столе разработчика: маленький OLED-экран с глазами, приложение на iPhone и «чёлка» на маке. Она видит, как ты работаешь с Claude Code, реагирует на это и помнит, как прошёл твой день.

## Зачем

- Работать с ИИ-агентами веселее, когда рядом кто-то живой. Иви показывает, что агент думает, ждёт тебя или закончил, и тебе не нужно смотреть в терминал.
- Вечером она рассказывает, что ты сделал за день. Через неделю помнит, что ты любишь засиживаться до трёх ночи.
- Проект строится в открытую: видео, devlog, быстрые релизы.

## Для кого

Сейчас для одного человека: для меня. Один пользователь, одно устройство, без аккаунтов. Если проект зайдёт людям, добавим остальных потом.

## Первая версия (MVP)

### 1. Реакции на Claude Code
| Что происходит | Что делает Иви |
|---|---|
| Новая сессия | Здоровается |
| Ты отправил запрос | Думает |
| Агент работает с файлами и командами | Сосредоточена |
| Агенту нужно твоё разрешение | Смотрит на тебя и машет, пока не ответишь |
| Задача готова | Радуется |
| Долго ничего не происходит | Засыпает |

### 2. Память
- **Короткая:** все события за сегодня по порядку.
- **Долгая:** каждую ночь день сжимается в короткую запись дневника и несколько фактов обо мне.
- **Итог дня:** вечером Иви показывает короткую сводку на экране и в приложении.

## Где живёт Иви

| Устройство | Роль |
|---|---|
| ESP32 + OLED 1.3" | Тело. Стоит дома, подключена по Wi-Fi |
| iPhone | Главное приложение: лицо, настроение, дневник. Позже Dynamic Island через Live Activities |
| Mac | Окно под чёлкой экрана в стиле Dynamic Island |
| Домашний сервер (Linux) | Мозг: бэкенд на Go в Docker. Доступ снаружи через Tailscale |

Все три экрана показывают одно и то же состояние. Источник правды один: бэкенд.

## Решения, которые уже приняты

- Бэкенд на Go, приложения на Swift, прошивка на C++.
- Устройства получают обновления через WebSocket, а не опросом.
- Сначала один пользователь.

## Что не входит в MVP

- Чат с Иви.
- Напоминания и таймеры фокуса.
- Bluetooth.
- Обновление Dynamic Island при закрытом приложении (нужен платный аккаунт Apple).
- Несколько пользователей.
